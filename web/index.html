    使用说明

    1. 接上画面手机装 PhoneCamera，和这台电脑同一个 WiFi，config 里填 camera_url。
    2. 开检测点下面的「AI 检测」chip。第一次点会加载模型，画面会停几秒。
    3. 开跟踪和预测跟踪给每个目标一个稳定 ID，预测才有的算。两个都开才看得到速度。
    4. 攒真值开「采集」录一段，回来看见真虫就标，标完喂 build_dataset。
    5. 激光先在 config 里把 laser.enabled 打开并选 backend，否则这里永远是灰色。
    6. 多路模型在 config 的 ai.models 里列几路就跑几路。每路的"每N帧"是能不能负担得起的关键 —— 人不需 25 fps，蚊子需要。
    中/EN 切换界面语言 点目标框 锁定该目标给激光 急停 任何状态都收光
